Méthodes de Paiement

Gérer les méthodes de paiement qui apparaissent dans la page de dons. Ajoutez le nom du compte et le numéro pour que les donateurs puissent envoyer de l'argent.

Seules les méthodes actives apparaîtront dans la page de dons. MonCash, NatCash, Kashpaw (Auto) sont traitées automatiquement via l'API PLOP PLOP — aucune saisie manuelle requise. Pour Carte Bancaire, choisissez type = stripe. Pour les virements bancaires, entrez le Nom et Numéro du compte.
